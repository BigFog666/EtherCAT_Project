## 板载 LED 演示

2026-10-05 灯版固件已烧录并校验；慢速演示两轮 PASS，分别为 3202 和 3102 周期，约 32/31 秒，操作者确认实际灯光符合预期。LED1 显示有效周期通信，LED2 显示实际使能，LED3/4 显示正负方向，LED5 显示应用故障；方向显示保持 300ms，以便观察小步进。

灯版固件 BIN SHA-256 为 `29f1a30cec8ae74ad211adf6e3dd23a30300ef8ecdb142ecf79d3c6e57ea4379`。2026-10-06 独立目录全新构建所得 BIN 摘要与此一致；当天没有重新烧录或运行板端演示。

上述灯光和固件摘要属于旧版。当前 `ssc_bridge.c` 将 LED1 空闲闪烁改为每 250ms 翻转一次，故障灯仍每 125ms 翻转一次。2026-10-09 的两轮慢速日志当前各为 3102 行，不能沿用旧版 3202/3102 的数字或 BIN 摘要。最新灯光逐项观察及不复位连续运行条件尚未完整记录。

## 实现边界

本工程提供真实 EtherCAT 通信和单轴模拟关节，状态机是 CiA402 教学子集。CSP/CSV 使用模型位置与速度，没有外接电机、编码器或电流/速度/位置闭环。故障停止是模型停止；原厂 SPI busy 等待未全面加入时限，应用超时也不覆盖 MCU 卡死。

未验收：物理拔线恢复、100ms 超时点精确测量、长时间稳定性、1ms 硬实时、DC、多轴、CST、TwinCAT 导入及完整 CiA402/ETG 一致性。10ms 与现有时间统计均为 Windows PC 侧短测条件。
