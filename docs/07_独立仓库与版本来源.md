# 独立仓库与版本来源

发布日期：2026-10-06。目标仓库：https://github.com/BigFog666/EtherCAT_Project 。

本项目从 [EtherCat_0to1](https://github.com/BigFog666/EtherCat_0to1) 中的 `EtherCAT_Hardware_Project` 独立整理。源提交为 `c5fe31303a574fa6cba04db981af77aed09f2d54`，源课程标签为 `hardware-lesson-H01`。本次只导出该子项目已归档的文件，没有导入原软件课程、私人简历、求职目录或原仓库的其他历史。

## 发布整理的变化

- 工程平铺为仓库根目录；common、firmware、master、tools 等相对结构保持一致。
- 首页沿用原项目的功能、目录、协议布局、构建运行与硬件说明风格，加入实测摘要、架构图与五灯说明。
- `prepare_soem.ps1` 可直接从上游准备固定提交，也可通过 `-Source` 复制已核对的本地 Git 源码；不要求存在原软件课程的同级目录。
- `build.ps1` 新增 `-BoardArchive`，从任意明确提供的商家 ZIP 路径恢复固件来源；保留原默认查找方式。
- 其余模型、PDO、桥接、主站、启动代码与链接脚本保持源归档版本。发布改动不代表新硬件版本已经烧录。
- 不进入版本库的原始日志与备份在文档中标为本地文件；关键结果留在可归档的 Markdown 和 measurements CSV。

## 课程状态与标签

H01 已完成框架阅读与练习范围，原答案与教师批注保留；H02 课件已准备、未完课。其余课程只有安排，未生成或完成。独立仓库的 `hardware-lesson-H01` 标签对应本次发布归档，不与原仓库提交哈希相同，也不伪造 2026-10-05 的建仓时间。

## 恢复资料

`firmware/generated` 是本地生成目录；课程中的相关文件定位用于准备后的本地阅读，GitHub 在线浏览看不到原 SDK。原日志、Flash/SII 备份不公开；有关结论可查 [首次联调](../evidence/2026-10-05_首次硬件联调.md)、[H01 校核及关键反馈](../evidence/2026-10-06_H01归档校核.md) 与 [时间统计摘要](../evidence/measurements/20261005_通信摘要.csv)。

商家 ZIP 需自行提供，当前生成器针对已核对的 SPI IO 基线，不承诺其他板卡 SDK 可直接替换。配置中的工具路径是原验证机路径，换机必须按实际安装修改。

本次独立目录的依赖下载、全新构建与测试结果见 [发布验证](../evidence/2026-10-06_独立仓库发布验证.md)。
