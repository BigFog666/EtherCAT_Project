以下表述基于已有硬件成果，适用于完成课程、能独立构建和复现演示，并解释代码与本人改动之后。当前仅 H01 完成阅读与练习，H02 已准备，不把未来课程状态写成已完成。

**基于 STM32F407 与 LAN9252 的 EtherCAT 单轴模拟关节控制系统**

**硬件环境：**STM32F407ZET6、LAN9252、ST-LINK、板载 LED

**软件环境：**C、CMake、GNU Arm GCC、OpenOCD/GDB、Windows SOEM 主站、Git

**功能概述：**基于商家 SSC 与 SOEM 参考工程完成 EtherCAT 主从通信与 CiA402 单轴模拟关节演示，实现位置/速度指令传输、状态反馈、故障处理及板载 LED 可视化。

**项目要点：**

- 基于 SSC/SPI PDI 从站与 SOEM 主站完成通信集成和验证，核对 CoE/SDO 对象访问及 12/12 字节 PDO 映射，实现目标指令与关节状态的周期交换。
- 完成 CiA402 教学子集的 CSP/CSV 模拟运动演示与修改验证，分析控制字/状态字、使能流程、快速停止、故障锁存及显式复位。
- 使用 CMake/GNU Arm 构建固件，结合 ST-LINK、OpenOCD/GDB 观察 SPI 寄存器和应用变量；通过板载 LED 显示通信、使能、运动方向与故障状态。
- 在 Windows 主站请求 10ms 周期下完成三轮短测，累计 627 次有效 PDO 交换、WKC 均为 3；结合日志和桌面行为测试核对通信及模型状态。

**项目链接：**https://github.com/BigFog666/EtherCAT_Project

项目日期按实际记录填写；硬件联调开始于 2026-10-05。不要用更早的软件课程日期冒充本板卡工程开始时间，也不预填未来结课日期。
